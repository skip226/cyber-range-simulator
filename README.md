# Cyber Range Simulator

An interactive, browser-based ethical-hacking learning environment built around guided modules and the **Defend the Node** cyber-defense mini-game.

## Live app

[Open Cyber Range Simulator](https://cyber-range-simulator.kenshinsega.chatgpt.site)

## Highlights

- Beginner-to-mastery cybersecurity learning path
- Ten critical, guided steps in each lesson module
- Interactive virtual monitor and simulated computer environment
- **Defend the Node** defensive-security mini-game
- Mission Control briefing with independent scrolling
- Difficulty selection and ready-to-start game flow
- Timed attack scenarios, performance statistics, progress bars, and ethical-hacker leveling
- Cyberpunk-inspired responsive interface
- Audio coaching and accessibility-focused larger text
- Persistent progress and replayable challenges

## Run locally

No build process is required.

1. Clone or download this repository.
2. Open `dist/index.html` in a modern browser.

For a local web server:

```bash
python3 -m http.server 8080 -d dist
```

Then visit `http://localhost:8080`.

## Ethical-use scope

This project is designed for legal, defensive cybersecurity education in a simulated environment. Practice only on systems you own or have explicit permission to test.
